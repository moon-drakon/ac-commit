AC Commit settings

Every accepted solution becomes a commit in your GitHub repo, dated at the time of the AC. Each problem keeps your latest AC.

1. Judges and repos

Enter your handle on each judge. Leave a judge unchecked to skip it. LeetCode uses the account you are logged in to, so its handle is optional.

HandleRepo name

Each repo must exist before you create the token. Create any that are missing: . An empty repo is fine. AC Commit adds the README.

2. GitHub token

  1. Create a fine-grained token. The name and permission are filled in.
  2. Under Repository access, choose Only select repositories and pick the repos above.
  3. Check that Contents is Read and write, then click Generate token.

The token stays in this browser's extension storage. AC Commit sends it only to api.github.com.

Advanced

The default author email is your GitHub noreply address, so the commits count on your contribution graph.
